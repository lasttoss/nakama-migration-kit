Where a player's data goes, and why the second run writes nothing

The write path and the record of it are the same storage write, which is why a run that dies between them is still idempotent: the next run does not ask the importer what it did, it asks the target. The second run takes 27.8 seconds against the first run's 41.4 and writes nothing - it is not faster because it skipped the work, it is the same work with the writes withheld, and that is the difference between a claim and a slogan.
